📖 Cryptographic Specifications & Architecture

SecureCrypt implements a zero-knowledge local-only cryptographic pipeline. Keys are derived and files encrypted locally inside the browser memory. Encrypted files can be securely shared with others or uploaded to AWS S3, while the server never holds the passwords or plaintext files.

Why SecureCrypt?

🛡️ Zero-Knowledge Architecture

Decryption occurs entirely inside the client browser. No plaintexts or keys are transmitted, processed, or cached by servers, shielding your data from third-party exposure.

⚡ Military-Grade AES-256-GCM

Using Advanced Encryption Standard in Galois/Counter Mode ensures confidentiality and cryptographic integrity validation (preventing file tampering attacks).

📱 Cross-Device Decryption

Files are packaged into a custom binary format (`.scf`) that can be decrypted on any browser, desktop device, or Java terminal without requiring external accounts.

🔑 Password & Key Options

Choose password-based key derivation (using secure PBKDF2) for everyday ease of use, or raw AES-256 key files (.sck) for advanced offline security workflows.
